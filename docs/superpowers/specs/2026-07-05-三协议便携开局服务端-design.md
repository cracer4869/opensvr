# 三协议便携开局服务端（opensvr）设计文档

- 日期：2026-07-05
- 状态：已定稿，待用户复核
- 第一原则：**实用、轻量、资源占用低**

## 1. 背景与目标

网络工程师携带自己的笔记本进机房给网络设备（华为/H3C/思科/锐捷等）开局，需要把
**版本补丁（固件）+ 配置文件**通过 FTP / SFTP / TFTP 供设备拉取，同时可接收设备回传
（备份配置）。

现有工具的问题：
- Xlight 免费个人版**不含 SFTP**，SFTP 是付费功能，30 天试用期后被禁用。
- FileZilla Server 只有 FTP/FTPS，无 SFTP。
- 需要同时带 Tftpd64（TFTP）+ SFTP 工具 + FTP 工具，零散。

目标：**一个绿色单 exe，同时提供 FTP + SFTP + TFTP**，无安装、无运行时依赖、无试用陷阱，
双击即用，现场好操作。

## 2. 技术选型

| 维度 | 决定 | 理由 |
|---|---|---|
| 语言/运行时 | **Go**（编译 Windows amd64 单静态 exe） | 天生绿色单文件、无运行时；三协议服务端库成熟；空闲占用极低 |
| 交互界面 | **系统托盘 + 本地 Web 管理页**（绑 127.0.0.1） | 现场直观；前端内嵌 exe；页面按需访问，不常驻 UI 进程 |
| 前端 | **原生 HTML/CSS/JS**，无框架 | 轻量、体积小、内嵌方便 |
| 配置 | 单个 `config.yaml`（exe 同级），无数据库 | 轻量、可手改 |

依赖精简（尽量少）：
- FTP 服务端：`github.com/fclairamb/ftpserverlib`
- SFTP：`github.com/pkg/sftp` + `golang.org/x/crypto/ssh`
- TFTP：`github.com/pin/tftp`
- 系统托盘：`github.com/getlantern/systray`（或等价轻量库）
- 配置：`gopkg.in/yaml.v3`

## 3. 架构（模块隔离）

```
main            装配所有模块 + 通过 go:embed 内嵌前端静态资源
├── config      读写 exe 同级 config.yaml，提供内置默认值
├── vfs         统一"根目录"文件系统抽象，三协议共用同一根目录；
│               强制路径穿越防护（禁止 ../ 越出根目录）；读写受控
├── auth        用户库（用户名/密码 + 匿名开关），FTP/SFTP 共用；TFTP 无认证
├── logbus      中央事件总线 + 内存环形缓冲（默认最近 500 条）；
│               各协议上报传输事件；Web 通过 SSE 订阅；可选写日志文件
├── netinfo     枚举本机所有网卡的 IPv4/IPv6 与子网（现场选对网段用）
├── ftp         封装 ftpserverlib：driver 接 vfs + auth；支持被动端口段
├── sftp        x/crypto/ssh 起 SSH 服务 + pkg/sftp 处理子系统；
│               主机密钥首次自动生成并持久化到 ./hostkey；接 vfs + auth
├── tftp        pin/tftp 处理 RRQ/WRQ（读/写），接 vfs；无认证
├── web         内嵌 HTTP 管理服务：静态页 + REST API + SSE 实时日志
└── tray        系统托盘：打开管理页 / 退出
```

各模块契约：
- `vfs`：对外暴露 `Open/Create/List/Stat/Remove`，输入路径一律经根目录归一化与越界校验。
- `auth`：`Authenticate(user, pass) -> (ok, isAnonymous)`；`AllowAnonymous` 开关。
- `logbus`：`Emit(event)`；`Subscribe() -> chan event`；`Recent() -> []event`。
- 三个协议模块统一接口：`Start() error` / `Stop() error` / `Status()`，互相独立，
  一个启动失败不影响其余两个。

## 4. Web 管理页功能

- 三协议各一个开/关开关，显示运行状态与实际监听端口。
- **醒目列出本机所有网卡 IP 与子网**（现场选对网段的关键）。
- 选择/修改共享根目录（固件、配置放这里）。
- 用户管理：默认 `admin/admin`；匿名开关（默认关，一键可开）。
- 实时传输日志（SSE 推送）+ 可选写日志文件。
- 一键"放行 Windows 防火墙"按钮：调用 `netsh advfirewall`，需管理员（触发 UAC）。

## 5. 默认配置（均可在 config.yaml 修改）

| 项 | 默认值 | 说明 |
|---|---|---|
| 根目录 | `./data`（exe 同级，不存在则自动创建） | 三协议共用 |
| FTP 端口 | 21 | 被动端口段 50000–50100 |
| SFTP 端口 | 22 | ⚠️ 若本机启用了 Windows OpenSSH Server 会冲突，改端口即可 |
| TFTP 端口 | 69 | 灌固件常用 |
| Web 管理页 | 127.0.0.1:8080 | 仅本机访问 |
| 主机密钥 | `./hostkey` | SFTP 用，首次自动生成并持久化 |
| 账号 | admin / admin | 设备侧按此登录；匿名默认关 |
| 日志缓冲 | 内存最近 500 条 | 可选同时写文件 |

## 6. 传输方向

读 + 写都支持：设备可从服务器**拉取**固件/配置，也可**上传**（备份）到根目录。
TFTP 支持 RRQ（读）与 WRQ（写）。

## 7. 错误处理与健壮性

- 端口被占用 → 该协议启动失败，Web 页红字提示具体端口与原因，**不影响其余两协议**。
- 根目录不存在 → 自动创建。
- SFTP 主机密钥缺失 → 首次自动生成并持久化。
- 路径穿越（`../` 越界）→ vfs 层拦截，返回权限错误并记日志。
- 所有传输事件（成功/失败/权限拒绝/登录失败）进 logbus，现场可查。

## 8. 资源占用约束（第一原则落地）

- 只有被启用的协议才创建监听与协程，未启用协议零开销。
- 日志用固定容量环形缓冲，内存上限可控。
- 前端原生实现，无框架，二进制体积小。
- 无后台数据库、无常驻额外进程（仅托盘 + 按需 Web）。

## 9. 测试策略

- 每个协议模块：单元测试 + 用 Go 客户端库做端到端自测（起服务 → 上传 → 下载 → 校验字节一致）。
- `vfs`：路径穿越/越界防护测试（重点）、读写权限测试。
- `auth`：正确/错误口令、匿名开关行为。
- `config`：默认值加载、缺文件容错、非法值处理。

## 10. 交付物

- `opensvr.exe`：Windows amd64 单文件，内嵌前端。
- `config.yaml`：可选；缺省使用内置默认。
- 使用说明 + 华为/H3C/思科开局侧命令示例（从笔记本拉固件、灌配置）。

## 11. 明确不做（YAGNI）

- 不做多用户配额/虚拟目录隔离（单一共享根目录即可）。
- 不做 FTPS/SCP/WebDAV（后续需要再加；SCP 与 SFTP 协议不同，个别老设备只认 SCP，
  到时按需评估）。
- 首版不做 Linux/arm 构建（Go 后续交叉编译即可）。
